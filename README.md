# 🏦 Mock Banking App — adirathore7.github.io

This repository contains a **mock banking web application** built for learning, experimentation, and UI/UX practice.  
It simulates core banking features such as viewing balances, transferring money, and navigating between service modules — all without real financial data.

The project is deployed using **GitHub Pages** and is accessible at:

👉 **https://adirathore7.github.io**

---

## 🚀 Purpose

This project was created to:

- Practice building interactive UI components  
- Explore state management patterns  
- Simulate real-world banking workflows  
- Experiment with responsive layouts  
- Build a safe, non-production banking interface  

No real transactions or sensitive data are used — everything is mock data.

---

## ✨ Features

- **Dashboard UI** showing mock account information  
- **Money Movement Module** with dynamic service cards  
- **Interactive components** (buttons, cards, modals)  
- **Routing & navigation** using React Router  
- **Responsive design** for desktop and mobile  
- **Clean component structure** for easy expansion

## 🧪 Running the App Locally

1. Clone the repository:

```
git clone https://github.com/adirathore7/adirathore7.github.io
```

2. Navigate into the project
```
cd adirathore7.github.io
```

3. Install dependencies:
```
npm install
```

4. Start the development server:
```
npm run dev
```

5. Then open the URL shown in your terminal (usually http://localhost:5173 or similar).

---

## 🌍 Deployment (GitHub Pages)
This project is deployed automatically using GitHub Pages.
To redeploy:
1. Build the project:
    ```
    npm run build
    ```
2. Push the build output to the gh-pages branch (if configured), or rely on your GitHub Actions workflow.
3. Visit: https://adirathore7.github.io
